# Разработка программных модулей

Учебные задания по разработке программных модулей. Каждая работа размещена в отдельной ветке со своими материалами и документацией.

## Работы

| Ветка | Тема | Содержание |
|---|---|---|
| [lesson_1](https://github.com/Resolushh/Development-of-software-modules/tree/lesson_1) | Backend и контракт сервиса | Разбор сценариев Steam, обработка ошибок и проверка окружения |
| [lesson_2](https://github.com/Resolushh/Development-of-software-modules/tree/lesson_2) | Cafe Report | Чтение CSV, расчёт выручки, среднего чека и отчёта по официантам |
| [lesson_3](https://github.com/Resolushh/Development-of-software-modules/tree/lesson_3) | Text Kit | Модули обработки текста, дат, статистики и валидации данных |
| [lesson_4](https://github.com/Resolushh/Development-of-software-modules/tree/lesson_4) | Младший разработчик: первая неделя | Практикум по модулям Go и сигнатурам функций |

## Просмотр задания

Выберите ветку на GitHub или переключитесь локально:

```bash
git switch lesson_2
```

README выбранной ветки содержит описание задания и, для программных проектов, команды запуска и тестирования.
