# Занятие 3. Text Kit

Практическая работа размещена в папке [text-kit](text-kit/). README проекта содержит описание, структуру, команды запуска и результаты проверок.

## Запуск

```bash
cd text-kit
python -m app.main
python -m unittest discover -s tests -v
```
