# Практикум «Младший разработчик: первая неделя»

**МДК.01.01 · Go · подписи функций и модуль проекта**

Практическая работа по разработке модулей на Go. Задания посвящены запуску проекта кассы, работе с модулем и зависимостями, структуре пакетов и составлению сигнатур функций для нескольких прикладных задач.

В практикуме рассматриваются электронный журнал колледжа, посещаемость, касса кофейни, абонементы фитнес-клуба, каталог книжного магазина и другие примеры.
