# Занятие 1. Backend и контракт сервиса

В домашнем задании разобрана работа backend на примере Steam: покупка игры, добавление в список желаемого и отправка сообщения другу.

Рассмотрены обработка запроса сервером, проверка данных, обращение к базе данных и возврат ответа клиенту. Для добавления игры в список желаемого описаны возможные сбои: потеря соединения, повторное нажатие и некорректные входные данные. Также зафиксирована проверка окружения Python, Git и Visual Studio Code.
